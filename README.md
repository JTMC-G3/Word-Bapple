# Word Bapple

A pass-the-phone party word game. Open `index.html` in any browser.

## How to play
1. Add 2–8 players and pick how many seconds each turn gets.
2. Go around the circle naming words that start with the letter in the bubble, starting with **A**.
3. No repeats. Run out of time (or press **I'm stuck**) and you're out.
4. As soon as someone is out, the letter moves on: A → B → C ...
5. Think a word is fake? Hit **Challenge**. If the group agrees, whoever said it is out.
6. Last player standing wins.

Options: **Type it** (words are checked for the right letter and repeats) or **Say it** (say it out loud and tap), a clock that speeds up every word, and skipping Q/X/Z.
